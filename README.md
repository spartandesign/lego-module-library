# PLTW LEGO Module Library

An independent teacher-and-student library of LEGO-compatible classroom testbed modules developed for PLTW Innovators & Makers activities.

## Local preview

```bash
npm ci
npm run dev
```

## Static build

```bash
npm run build
```

The static site is exported to `out/`. The included GitHub Actions workflow sets the repository base path and deploys that folder to GitHub Pages.

## Module downloads

The streamlined ZIP files in `public/downloads/` contain the primary printable parts and assembly README for each module. Fit coupons and not-for-print reference meshes remain in the source project rather than the public download packs.
