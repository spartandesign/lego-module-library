# Superseded potentiometer downloads

These packages are retained only as development-history evidence and are kept
outside `public/` so they cannot be downloaded from the deployed Module
Library.

- `v1-1-dual-mount-3p4` and the earlier edge-tab package use circular tabs on
  the short ends. The +X tab blocks the middle SIG M3 nut-loading path.
- `v1-2-open-tabs-anchor-feet` moves the tabs to the correct long sides, but a
  physical support-free print showed failed bridge strands across the cavity
  roof because its 11 non-gripping support centers remained hollow.
- `v1.zip` is the older LEGO-only foundation and is not the current supported
  classroom package.

Use only `potentiometer-control-dial-module-v1-3-solid-supports-anchor-feet.zip`
from `public/downloads/`. It has rectangular open long-side tabs, an
unobstructed loading path for all three M3 nuts, 11 solid non-gripping roof
supports, and four open Coupon-F clutch bores with C anchor feet.
